Robotics & autonomy projects

A selection of recent work across sim-to-real locomotion, teleoperation, simulation infrastructure and navigation for real robots.

Case 1

Sim-to-Real Pipeline for Humanoid Motion

Isaac Sim → MuJoCo → Real humanoid robot

Building and tuning a sim-to-real locomotion pipeline for a humanoid robot, combining NVIDIA Isaac tools with MuJoCo and deployment on real hardware.

  • Designed a pipeline from Isaac Sim to MuJoCo and finally to the real robot.
  • Tuned joint-level PD control (Kp/Kd) for stable and responsive motion.
  • Modified simulation and controller code to support new behaviors and constraints.
  • Compared motion quality between simulation environments and real hardware.
  • Implemented locomotion constraints to keep motions safe and feasible.
Case 2

Hand Teleoperation & Sensor-Based Gripper/Finger Work

Teleoperation with rich sensing for robot hands

Developing a teleoperation setup for robot hands and grippers with integrated sensing to enable precise and robust manipulation in both simulation and reality.

  • Implemented teleoperation control for robot hands and multi-fingered grippers.
  • Integrated sensors for fingers and grippers to improve contact awareness.
  • Worked with camera and LiDAR data to support perception-driven manipulation.
  • Controlled hands across real and simulated stacks, keeping interfaces aligned.
  • Performed systematic testing and validation on both real and simulated setups.
Case 3

Simulation Infrastructure in Isaac Sim

Scalable scenes & tools for multi-robot experiments

Building robust scenes and tooling in Isaac Sim to support realistic physics, multi-robot setups and rapid experimentation.

  • Created scenes with realistic environments and robot assets.
  • Configured collisions and contacts to match real-world behavior.
  • Tuned robot physics and URDF/USD parameters for stability and fidelity.
  • Constructed multi-robot scenes, including forklifts and other construction robots.
  • Used action graphs and object loading pipelines for flexible scenario setup.
Case 4

Navigation & Real Robot Deployment

Nav2 pipeline on real hardware

End-to-end navigation pipeline using Nav2 and ROS 2, from mapping and perception to debugging and deployment on real robots in challenging environments.

  • Assembled and tuned the Nav2 pipeline for mobile robots.
  • Worked with LiDAR, odometry and mapping to create robust navigation stacks.
  • Ran quality checks (QC) for autonomy behavior in realistic environments.
  • Deployed and debugged the stack on real robots, including network issues.
  • Handled hardware failures and edge cases in the field.
