Robotics & autonomy projects

A selection of recent work across sim-to-real locomotion, teleoperation, simulation infrastructure and navigation for real robots.

Case 1

Sim-to-Real Pipeline for Humanoid Motion

Isaac Sim → MuJoCo → Real humanoid robot

Building and tuning a sim-to-real locomotion pipeline for Unitree H1-2 humanoid robot, combining NVIDIA Isaac tools with MuJoCo and deployment on real hardware.

  • Designed a pipeline from Isaac Sim to MuJoCo and finally to the real robot.
  • Tuned joint-level PD control (Kp/Kd) for stable sim-to-real transfer.
  • Modified simulation and controller code to support new motions.
  • Compared motion quality between simulation environments and real hardware.
Case 2

Hand Teleoperation & Gripper/Finger Control

Teleoperation of Unitree robot hands with Apple headset

Configuring an existing Unitree teleoperation system for robot arms using an Apple headset and VR controllers, including developing grippers motion driven by trigger input.

  • Configured teleoperation control for robot arms and hands grippers.
  • Used VR controllers so that finger closure on the robot side was triggered by pressing the controller triggers.
  • Worked with camera and LiDAR data, configuring their SDKs and reading data on the robot.
  • Verified touch sensor behaviour on Inspire Hands robot grippers.
Case 3

Simulation Infrastructure in Isaac Sim

Scalable scenes & tools for multi-robot experiments

Building robust scenes and tooling in Isaac Sim to support realistic physics, multi-robot setups and rapid experimentation.

  • Created scenes with realistic environments and robot assets.
  • Configured collisions and contacts to match real-world behavior.
  • Tuned robot physics and URDF/USD parameters for stability and fidelity.
  • Constructed multi-robot scenes with a construction robot, a manipulation arm and other robots.
  • Used action graphs and object loading pipelines for flexible scenario setup.
Case 4

Navigation & Real Robot Deployment

Nav2 pipeline on real hardware

End-to-end navigation pipeline using Nav2 and ROS 2, from mapping and perception to debugging and deployment on real robots in indoor environment.

  • Assembled and tuned the Nav2 pipeline for Unitree H1-2 humanoid robot.
  • Worked with LiDAR, odometry and mapping to create robust navigation stacks.
  • Ran a computer-vision-based QC pipeline for construction-related checks and for detecting humans and their hands.
  • Deployed and debugged the stack on real robots, including network issues.
  • Handled hardware failures and edge cases in the field.
